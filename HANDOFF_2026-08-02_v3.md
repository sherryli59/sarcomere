# Sarcomere assembly handoff — motor drive is the assembly bottleneck

Date: 2026-08-02 (supersedes `HANDOFF_2026-08-02.md`)
Repository: `/home/groups/rotskoff/sherry/sarcomere/sarcomere`

## Executive summary

The previous handoff attributed the failed 1,280-actin pilot to nonspecific
titin capture and prescribed an ACTN2-support gate. That gate was implemented
and works exactly as specified — zero unsupported associations in every run
since. **It was not the blocking defect.**

The blocking defect is **myosin motor drive**. Production had drifted to 141
heads per half at full tonic activation (`am_activation_floor=1`,
`active_fraction=1`), roughly 8x the drive of the minimal cell that passed its
gate (35 heads, floor 0, fraction 0.5). At that drive myosin occupies the entire
thin filament, the crosslinkable segment left for ACTN2 collapses to a median of
zero by 15 ms, the Z-disc network starves, and no registered structure forms.

Restoring the minimal cell's drive fixes it. At 100 ms the model now produces
**96 mature status-2 links at an A-A overlap of 0.1050 +/- 0.0100 um** against
the 0.10 um target. At full drive the same run yields 13 mature links drifting
off-target to 0.0821 +/- 0.0204 um.

## The measurement chain

Each step was measured, not inferred. Numbers are 640 actins / 320 myosins at
production density unless stated.

1. **Titin occupancy is exactly the cumulative union of ever-ACTN2-supported
   actins** (ratio 1.00–1.08 at every frame, every seed, both sizes). Titin was
   a ratchet: a fast, memoryless licensing process feeding an effectively
   irreversible latch.
2. **ACTN2 links die geometrically, not chemically.** 109 of 158 links vanished
   in 20 ms where the 1 s status-1 lifetime predicts ~3. Median age at death
   5.9 ms; 21% die within 1 ms of forming.
3. **The crosslinkable segment collapses.** `crosslink_ratio` falls 1.0 -> 0.02,
   median zero by 15 ms, 95.8% of actins below 0.05 by 100 ms. Myosin head
   counts grow without bound (0 -> 22,564 weak, 0 -> 18,823 strong).
4. **Orientation is not the limiter.** Nematic order develops (S 0.03 -> 0.87)
   but polar order stays flat (P ~ 0.03), so antiparallel pairs become *more*
   common (0.25 -> 0.49). Available filament length is the limiter, not
   filament orientation.
5. **Head occupancy, not sliding speed, is the controlling variable.** ACTN2
   fraction is perfectly monotonic in heads-per-actin (14.3 -> 0.097,
   6.9 -> 0.128, 3.1 -> 0.186, 3.0 -> 0.208, 1.4 -> 0.223) and non-monotonic in
   drift.

reduce heads-per-actin, which is what the ACTN2 network responds to.

Total ACTN2 plateaus near 0.30 by ~50 ms; what continues is *conversion* from
encounter complex to registered link. A-M overlap stays bounded (1.10 -> 1.68,
versus 0 -> 7.5 at full drive). Zero unsupported associations, zero ruptures,
force caps ~1e-6.

Full drive over the same 100 ms: 13 mature links at 0.0821 +/- 0.0204 um, count
collapsing from a peak of 49, standard deviation widening 2.4x.

## Corrections to earlier conclusions

Recorded because each was stated with more confidence than the evidence
supported, and each cost time.

- **The sliding throttle (`am_overlap_target_ratio`) is not the missing
  setting.** The minimal cell does not set it either; it reached a finite
  0.37 um A-M overlap without it. Direct test: throttle at 0.25 and 0.40 changed
  nothing (drift 2.80/3.13 vs 3.13 baseline, network still collapsing).
- **Sliding speed is not the root cause.** The heads-only run has 8x the drift
  of the activation-only run yet a healthier network on every measure. Drift is
  a correlate of head occupancy, not the driver.
- **`crosslinkable_ratio` is the operative mechanism after all.** It was
  dismissed too quickly. What was wrong was the proposed driver: heads occupy
  the filament, sliding does not sweep links off sites.
- **There is no maturation/survival trade-off.** That appeared only because it
  was measured at 20 ms, before maturation begins. Over 100 ms the reduced drive
  wins on both count and register.
- **The 20 ms guarded window is too short to see the science.** It certified two
  1,280-actin production runs that contained no registered structure at all.

## Code changes

All in the production tree; originals backed up to
`/scratch/users/xsli/sarcomere/src_backup_pretitingate_20260802/`.

- `--titin_require_live_actn2` — formation-only ACTN2-support capture gate.
- `--titin_k_off_unsupported` — serial actin–ACTN2–titin anchor. Titin reaches
  actin through ACTN2, so the composite lifetime is set by its weakest element.
  Zero preserves single-rate behaviour and the minimal cell's result exactly.
- `--titin_rebind_requires_actn2` — the rebinding memory keeps its x100 rate
  advantage but loses its exemption from the support requirement. Without this
  the serial anchor is a null: 94% of unsupported releases were undone by an
  exempt recapture on the next step.
- `--am_heads_per_half`, `--am_activation_floor`, `--am_activation_active_fraction`
  plumbed through the run script.
- Titin schema 2 -> 4; resume guard rejects older trajectories.
- `/state/titin_association_counts` — cumulative
  {supported, unsupported, rebind, unsupported_releases}, survives resume.
- Titin event code 3 marks release without live ACTN2.

Tests: `cpp/tests/titin_actn2_capture_gate_test.cpp`, 10 cases. All 25 ctest
tests pass. The test is self-controlling — gate-off and gate-on cases share
geometry and give 2 bound vs 0 bound.

Analysis: `analysis/titin_occupancy_timeseries.py` now applies a time-aware
maturation criterion (missing status-2 is a warning below 40 ms, a failure at or
above it, since status-2 first appears at 24–36 ms) and a power-aware turnover
check (integrates bound population; fails only if >= 3 releases were expected).

## Open questions

1. **Does the plateau hold?** Total ACTN2 dipped 0.313 -> 0.283 over the last
   10 ms of the 100 ms run. 200 ms runs (2 seeds) and a 1,280-actin 100 ms run
   are in flight to distinguish steady state from slow erosion.
2. **Is the reduced head count defensible?** 35 heads/half against a real ~150.
   Activation alone fixes drift but only partly restores the network. The
   principled version is probably a physiological duty ratio (~2–5% attached;
   this model runs ~31%), giving load without occupancy. Untested.
3. **Does a Z-disc form, or just registered pairs?** 96 links at the correct
   overlap is necessary, not sufficient. Lattice-level order (phi3d, hexagonal
   registration) has not been measured on these runs.
