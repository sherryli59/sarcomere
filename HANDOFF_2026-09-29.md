## Executive summary

**The ACTN2 `am_overlap_occlusion` veto was the primary cause of Z-disc failure
in the minimal sarcomere rig, and it is not the rule the design calls for.**

Two deletion rules exist for ACTN2-vs-thick-filament conflict:

- **reason 4, `actn2_myosin_collision`** — the physical one. Fires when the
  ACTN2 connector penetrates the thick filament by
  `aa_occlusion_rupture_penetration` = 0.010 um. **MEASURED: 0 events, and
  connector penetration is exactly 0.000000 across 66383 link-frames**, because
  the radial sterics hold the actin ~11.5 nm clear of the thick-filament surface.
- **reason 3, `am_overlap_occlusion`** — a proximity-coverage proxy. Fires with
  probability 1, no penetration and no contact force required, when the thick
  filament's **capture** envelope (0.130 um = sterics 0.080 + `am_cutoff` 0.050
  of myosin HEAD REACH) covers the actin's whole barbed contour. **MEASURED: 123
  events, 23% of all detachments, and 100% of them once the bond was made
  permanent.**

So the physically motivated rule never triggers and the proxy does all the
damage. Disabling only the proxy (`--aa_overlap_occlusion_veto=false`, leaving
the repulsion and reason 4 in force) in the one completed paired seed:

| seed 20260835 | veto ON | veto OFF |
|---|---:|---:|
| ACTN2 pairs linked, last 0.5 s | 0.00 | **2.00** |
| frames with any link alive | 32.7% | **100%** |
| last frame with a live link | 1637 ms | **5000 ms (full run)** |
| status-2 count, last 0.5 s | 0.00 | **10.43** |
| Z-disc pair (0,1) angle | 4.3 deg | **2.2 deg** |
| Z-disc pair (2,3) angle | **79.9 deg** | **3.7 deg** |

Angle is `180 - arccos(u_a . u_b)`; 0 = perfectly antiparallel. Final-frame
values, cross-checked between the HDF5 source and the viewer payload.

**n = 1 seed, and it is the most favourable control seed** (835 survived 1637 ms
vs 263/520/753 ms for the other three). Treat as a strong hypothesis, not a
result. See In flight.

## Code changes (uncommitted, both default-inert)

### 1. `aa_occlusion_capture_radius` (double, default -1)

Decouples the occlusion veto's capture distance from the AM capture centreline.
`<= 0` reuses the AM value, which is bit-identical. Clamped with `std::min` to
the AM centreline so the existing broad phase stays conservative. Patched at
**both** `analyze_am` sites — `sarcomere.cpp:1784` (static) and `:2635`
(dynamic_am) — because only the dynamic one is live under `--dynamic_am=true`
but patching one would leave a silent inconsistency.

Gates (job `45795904`), all PASS: flag unset is byte-identical to
`git archive HEAD` across 215 datasets; flag on changes the trajectory
(143 datasets); the value reaches `meta@aa_occlusion_capture_radius`.

**This flag must not be used as-is. See Corrections.**

### 2. `aa_overlap_occlusion_veto` (bool, default true)

`false` skips the reason-3 deletion only. The radial repulsion (hard core
0.065 um at `am_steric_k` = 1000 pN/um) and the reason-4 penetration deletion
are untouched.

Gates (job `45957025`), all PASS: default byte-identical to HEAD; `=false`
changes the trajectory (171 datasets); reason 3 goes 5 -> **0** while the
control had events to suppress, with reasons 2 and 4 still live;

### 3. Contact guard on the dynamic_am min-update — APPLIED BUT INERT

guard. **It is a no-op at the default radius** and should be understood as a
precondition for any reduced radius, not a fix. See Corrections.

## Key measurements

### The occlusion veto's own geometry

`crosslinkable_ratio` = run of actin from its barbed tip to the first point
within capture radius R of ANY thick filament, **minimised over myosins**, reset
to 1 each step. The veto fires when it is `<= EPS`, and `EPS` here is
**1e-6** from `sarcomere.h:33` (the function's own default of 1e-12 is not what
the call site passes) — i.e. 1 nm of free contour on a 1 um actin.

R is a **3-D capsule** radius, not an axial gap: `subsegment_within_distance`
uses full 3-D norms. Every neighbouring constraint decomposes axial from
transverse (`aa_zdisc_tip_*`, `aa_barbed_lateral_*`, myomesin); this one does
not. Consequence: its effective axial reach is `sqrt(R^2 - r^2)` and drifts with
the radial offset r. MEASURED: the veto fired across a 65 nm spread of
barbed-tip-to-filament-end clearance (10-90 pct 0.043 to 0.108 um) for what is
nominally one threshold.

### Operating separation — the number that constrains every radius

Actin-to-nearest-thick-filament closest approach, segment-to-segment, first 1 s:

| | value (um) |
|---|---:|
| t = 0 | 0.075 - 0.079 |
| median | 0.076 - 0.079 |
| p10 | 0.068 - 0.070 |
| sd while intact | 0.0045 - 0.0060 |
| % > 0.080 | 15 - 47 |
| % > 0.130 while intact | **0.0** |
| % > 0.130 after collapse begins | 2.5 - 26 |

`am_preferred_centerline` (0.080) and the steric sum (myosin 0.050 + actin 0.015
+ gap 0.015 = 0.080) are the **same number by construction**, so "use the steric
radius" puts a threshold exactly on the operating point: 0 sigma of margin.

### The clearance is an unbiased random walk

For each actin, with its partner thick filament FIXED at t = 1 ms, the signed
clearance g of the barbed tip past the filament end:

| group | n | window (s) | g0 (um) | mean dg | sd | SEM |
|---|---:|---:|---:|---:|---:|---:|
| motor ON | 36 | 0.53 | +0.206 | **+0.0001** | 0.159 | 0.027 |
| motor OFF | 32 | 0.94 | -0.028 | +0.168 | 0.449 | 0.079 |

Lag-resolved dispersion of dg over motor-ON runs, intact window only:

| lag (ms) | n | mean dg (um) | sd dg (um) | sd / sqrt(lag) |
|---:|---:|---:|---:|---:|
| 4 | 4728 | +0.00000 | 0.01051 | 0.166 |
| 16 | 4620 | +0.00003 | 0.02045 | 0.162 |
| 64 | 4188 | +0.00019 | 0.04459 | 0.176 |
| 256 | 2720 | +0.00027 | 0.08877 | 0.175 |

`sd / sqrt(lag)` flat across a 64x range; fitted power-law exponent **0.523**
against 0.5 for free diffusion; mean zero at every lag. D_eff = 0.0154 um^2/s
vs 0.381 free, so the structure confines the clearance **25x tighter than free
diffusion** and still without bias. There is no directed burial: any net inward
drift is under ~0.1 um/s against an unloaded shortening velocity of 5 um/s.

### Nothing stops the actin axially

- RADIAL is fine: `compute_actin_myosin_radial_repulsion_result` runs in
  `_volume_exclusion()`, hard core 0.065 um at 1000 pN/um. Rarely even engaged.
- AXIAL has no stop against the actin's OWN thick filament. An axial end-stop
  exists, `compute_actin_myosin_repulsion` (`interaction.cpp:1677`) — its radial
  block is entirely COMMENTED OUT and it returns `k*(Lm-|s|)/Lm` along the
  myosin axis, a force that RAMPS TOWARD THE MIDLINE to 1000 pN at s = 0. But
  its only live caller (`_calc_am_force_velocity`) applies it only to thick
  filaments the actin is NOT bonded to and only inside a bonded myosin-myosin
  pair; the other call site is downstream of `if (dynamic_am) { continue; }`.
- MEASURED, 4/4 seeds: the actin **barbed** tip reaches |s| = 0.0000 um, the
  M-line exactly, and crosses it (first crossing 287/407/755/1263 ms). The tip
  sits inside the thick-filament axial span 45-61% of frames.

**The user judged this end-stop not physical** (a force ramping to 1000 pN at the
midline) and deferred it. Do not wire it up without revisiting that.

### Per-link vs per-actin occlusion — a settled negative

The veto is per-actin (`actin_crosslink_ratio`, min over myosins) but deletes
per-link, and every link's attachment coordinates `s_i`, `s_j` are logged. A
paired estimator — `delta = d_site - d_tip`, both at the same frame against the
same myosin, so the frame-lag cancels because tip and site are on the same rigid
rod — gives median **+0.0005 um**, mean -0.0052 +/- 0.0034 (SE), n = 58,
51.7% positive. The attachment site is as buried as the barbed tip to within
~5 nm. Attachments sit a median 37 nm along the actin from the tip and the actin
runs nearly parallel to the thick filament, so every link on an actin becomes
occluded at the same instant. **A per-link rule would delete the same links.**

## Corrections to earlier conclusions

1. **"The links stayed put in the permanent-bond run and the filaments splayed
   anyway."** WRONG, and it was reported to the user. `sarc4L` (base_lifetime
   100 s) has `links_tail 0.00`, any link alive in only **11.1%** of frames, last
   link at **234 ms**. The 100 s lifetime removed stochastic death exactly as
   intended (0 stochastic events) and occlusion deleted all 8 links anyway. The
   69 deg splay then developed over 4.8 s **with no links present**. The
   inference "bond lifetime controls how often a link is there, not whether the
   structure holds its shape" was built on a false premise.

2. **"Shrinking the veto radius to the steric value will fix it."** WRONG,
   tested, 14x worse: occlusion events 29 -> 421, occlusion share 26% -> 68%,
   first occlusion at t = 0 in all 4 seeds. Cause: `subsegment_within_distance`
   returns `(0, A, A)` when out of range, so **`crosslinkable_ratio == 0` means
   both "contour consumed" and "no contact at all"**. At R = 0.080 the actin's
   0.0765 +/- 0.005 separation straddles the boundary, so 35-65% of the
   occlusions were the degenerate branch. The comment at `sarcomere.cpp:2623`
   already warned about exactly this.

3. **"The 0.130 radius is head reach sloppily conflated with sterics."** WRONG.
   It is deliberate margin: 0.080 contact distance plus 0.050, about 10 sigma
   against the measured 5 nm wobble. Any candidate radius must clear 0.0765 by
   several sigma — 0.100 gives ~4.7, 0.080 gives ~0.8.

4. **"The missing contact guard on the dynamic_am path is a production bug."**
   WRONG. `dynamic_am` iterates only `bound_actins` (heads with
   `bound_actin >= 0 && state != detached`), which already implies contact.
   Adding the explicit guard is **bit-identical over 2001 frames with 1518
   frames of opportunity** (an actin outside the 0.130 capsule from 471 ms on).

5. **"44.8% of deleted attachment sites were in free space."** RETRACTED as
   sampling error. `crosslinkable_ratio` hits zero exactly when the capsule
   boundary touches the barbed tip, so d_tip == R **by construction** at the
   event. Sampled 0.31 ms away it reads 7 nm over and the binary test flips 81%
   of the time. **Any binary in/out test against R is unusable at
   save_every = 100.** The control is: d_tip must be inside at the event; it
   measured inside only 19% of the time, and `crosslink_ratio == 0` at the
   nearest frame only 12%.

6. **`d_tip` at occlusion = +0.078 um and the end-stop engaged at only 15% of
   deletions** — these two SURVIVE. They compare quantities 28 nm apart against
   ~3 nm of lag motion, not a threshold-pinned binary. But the mapping of the
   veto onto the end-stop's axial coordinate is **empirical, not an identity**:
   the veto is 3-D, so there is no radius that guarantees it fires inside an
   axial onset. It only shifts the distribution.

## Open questions

- Does the veto-off result hold across seeds, or is 835 special? It was the best
  control seed by a factor of 2-6 in survival time.
- The **formation** gates (`sarcomere_actn2.cpp:196`, `:293`) still restrict new
  ACTN2 attachments to the free contour using the same overloaded ratio. Left
  deliberately untouched so the veto-off experiment has one knob. If links
  survive but cannot re-form after a transient, that is why, and it is a second
  flag.
- Is there a defensible replacement for reason 3 at all? The filaments never
  overlap — they run side by side 11.5 nm apart — so "the thick filament occupies
  the barbed contour" is never literally true. The real question is whether the
  ACTN2 rod has a clear path from actin i to actin j, which depends on where the
  thick filament sits **azimuthally** between them. The current rule has no
  azimuthal awareness. Never tested.
- `titin_rest_length` = 0.665 um against a measured span of 0.29-0.32 (minimal)
  and 0.50-0.54 (production), taut only 14-24% of the time in production at
  0.19-0.48 pN. Where did 0.665 come from? Note titin is TENSION-ONLY
  (`force = k*max(0, d - slack)`) so it cannot resist burial in either rig —
  shortening the rest length would pull the barbed tip further in.
- Myomesin still untested: `k_mm = 0` in every run, 0 bridges, and the radial
  capture window is [0.070, 0.150] um while thick filaments sit far outside it.
